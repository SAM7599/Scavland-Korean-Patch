# Scavland 한국어 패치 (비공식)

Scavland를 한국어로 즐길 수 있게 해주는 비공식 번역 패치입니다.

Scavland는 영어, 일본어, 중국어 등 11개 언어를 정식 지원하지만 한국어는
아직 없습니다. 이 패치를 설치하면 게임 내 모든 텍스트(9,842줄 전체)가
한국어로 번역되어 표시되고, 그냥 번역만 밀어넣었을 때 흔히 생기는
"한글이 네모(□)로 깨지는 문제"도 폰트까지 손봐서 해결해 놓았습니다.
번역·설치 모두 별도 설정 지식 없이 파일 하나만 실행하면 끝나도록
만들었습니다.

## 이런 분께 추천드려요

- 영어(또는 다른 외국어) 텍스트 때문에 스토리나 대사를 온전히 즐기기
  어려웠던 분
- 자동번역기를 계속 돌려가며 플레이하기 번거로웠던 분
- 한글 패치를 처음 써봐서 설치가 복잡할까 걱정되는 분 (설치 프로그램이
  거의 다 알아서 해줍니다)

## 무엇이 한국어로 바뀌나요

메인 메뉴, 설정, 아이템, 퀘스트, NPC 대화 등 게임에서 볼 수 있는
텍스트 44개 항목(총 9,842줄)이 전부 번역 대상입니다. 대화창처럼 원래
한글이 깨져서 표시되던 화면도 포함해서, 게임을 플레이하는 동안 보이는
글자는 사실상 전부 한국어로 나온다고 보시면 됩니다.

픽셀 그래픽 게임이라는 점을 고려해서, 한글 서체도 매끈한 일반 폰트
대신 "갈무리(Galmuri)"라는 도트(픽셀) 느낌 폰트로 골랐습니다.

## 설치 방법

1. **Scavland 게임을 완전히 종료**합니다. (실행 중이면 설치가 안 됩니다.)
2. 이 저장소의 [Releases](../../releases) 페이지에서 최신 압축 파일을
   내려받아 원하는 폴더에 압축을 풉니다.
3. 압축을 푼 폴더 안의 `Install_KR_Patch.vbs`를 더블클릭해서 실행합니다.
   (검은 콘솔 창 없이 설치 프로그램 창만 뜹니다.)
4. 설치 프로그램이 게임이 설치된 폴더를 자동으로 찾아줍니다. 혹시 못
   찾으면 "찾아보기" 버튼으로 직접 게임 폴더를 선택해 주세요.
5. "패치 설치" 버튼을 누르고 완료될 때까지 기다립니다.
6. 게임을 실행한 뒤 설정(Settings) > 언어(Language) 메뉴에서 "한국어
   (Korean)"를 선택합니다. (원래 "포르투갈어"가 있던 자리에 새로
   나타납니다.)

혹시 설치 중 문제가 생기면, 설치 프로그램과 같은 폴더에 만들어지는
`error_log.txt` 파일을 확인해 보세요. 설치 창이 아예 뜨지 않는다면
같은 폴더의 `Install_KR_Patch_Console.bat`을 대신 실행해 보시면
됩니다(콘솔 창에 오류 내용이 그대로 표시됩니다).

## 스팀덱(Steam Deck)에서 사용하는 방법

패치 내용 자체(번역·폰트)는 스팀덱에서도 문제없이 그대로 작동합니다.
다만 위 설치 프로그램(`Install_KR_Patch.vbs`)은 윈도우 전용이라
스팀덱의 데스크톱 모드(리눅스)에서는 실행할 수 없어서, 스팀덱용으로
별도의 설치 스크립트를 함께 배포하고 있습니다.

1. **Scavland 게임을 완전히 종료**합니다.
2. 스팀덱을 **데스크톱 모드**로 전환합니다. (전원 버튼 길게 눌러서 나오는
   메뉴 → "데스크톱으로 전환")
3. [Releases](../../releases) 페이지에서 압축 파일을 내려받아 압축을
   풉니다. (압축 안에 `bin` 폴더와 `Install_KR_Patch_SteamDeck.sh`
   파일이 같이 들어 있습니다.)
4. 터미널(Konsole)을 열고, 압축을 푼 폴더로 이동한 뒤 아래 두 줄을
   차례로 입력합니다.

   ```
   chmod +x Install_KR_Patch_SteamDeck.sh
   ./Install_KR_Patch_SteamDeck.sh
   ```

5. 게임 폴더를 자동으로 찾아줍니다. 혹시 못 찾으면 화면에 나오는
   안내에 따라 게임 폴더 경로를 직접 입력해 주세요.
6. `1`을 입력해 "패치 설치"를 선택합니다.
7. 설치가 끝나면 게임 모드로 돌아가 게임을 실행하고, 설정(Settings) >
   언어(Language)에서 "한국어(Korean)"를 선택합니다.

패치를 지우고 싶을 때는 같은 스크립트를 다시 실행해서 `2`(되돌리기)를
선택하면 됩니다.

## 패치를 지우고 싶다면

게임을 원래 상태로 되돌리고 싶을 때는 설치할 때 썼던 프로그램
(`Install_KR_Patch.vbs`)을 다시 실행해서 "되돌리기 (제거)" 버튼만
누르면 됩니다. 설치 전 원본 파일을 자동으로 백업해 두기 때문에
게임 파일을 다시 받을 필요 없이 바로 복구됩니다.

## 설치 전에 알아두시면 좋은 점

- 이 패치는 게임에 원래 있던 "포르투갈어(브라질)" 언어 자리를 한국어로
  바꿔치기하는 방식입니다. 그래서 패치를 쓰는 동안에는 포르투갈어를
  선택할 수 없게 됩니다. (한국어를 지우면 포르투갈어도 다시 선택할 수
  있습니다.)
- 대화창에 나오는 NPC 이름이나 일부 소속 라벨은 번역 대상 밖에 따로
  저장돼 있어서 영어로 보일 수 있습니다. 게임 플레이에는 지장이 없는
  사소한 부분입니다.
- 게임 핵심 데이터 파일 하나를 통째로 교체하는 방식이라 패치 용량이
  꽤 큽니다. 설치 전에 게임이 설치된 드라이브에 여유 공간을 넉넉히
  (400MB 정도) 남겨 두세요.
- 게임이 업데이트되면 내부 파일 구조가 바뀌어서 패치가 더는 맞지 않게
  될 수 있습니다. 업데이트 이후 문제가 생기면 이 저장소에 새 버전이
  올라왔는지 먼저 확인해 주세요.
- 이 패치는 개발사·퍼블리셔와 관련 없는 개인 팬 번역입니다.

## 사용한 폰트

한글 표시에는 도트 폰트 [갈무리(Galmuri)](https://galmuri.quiple.dev)를
사용했습니다. OFL-1.1 라이선스로 자유롭게 배포되는 폰트이며, 제작자는
quiple입니다.

## 번역 원칙 (이름이 낯설게 느껴지신다면)

플레이 중에 "어, 이 이름이 왜 이렇게 번역됐지?" 싶은 경우가 있을 수
있습니다. 예를 들어 게임에 나오는 권총 "PM 니콜라이(PM Nikolay)"는
실제로는 러시아제 마카로프(Makarov) 권총을 본뜬 무기이지만, 게임
개발사가 원래부터 "마카로프"라는 실제 이름 대신 "Nikolay"라는 가상의
이름을 붙여 놓았습니다. (실제 상표/모델명을 그대로 쓰지 않으려고 이름을
바꿔 넣는 건 여러 게임에서 흔한 방식입니다.)

이 패치는 이런 경우 게임이 실제로 붙인 영어 이름을 임의로 "더 익숙한"
현실의 이름으로 바꾸지 않고, 원문 그대로 한국어 발음으로 옮기는 것을
원칙으로 하고 있습니다. 그래서 "마카로프"가 아니라 원문 그대로
"니콜라이"로 번역되어 있으며, 다른 무기나 인물 이름들도 전부 같은
기준을 따릅니다. 오역이 아니라 의도한 번역 방식이니 참고해 주세요.

## 오타를 발견하셨거나 문제가 있다면

번역 오타, 어색한 표현, 설치 중 겪은 문제 등은 무엇이든 [ScavLand Korean project](https://steamcommunity.com/groups/Scavland_KR_project) 스팀그룹에 남겨 주시면 확인 후 다음 버전에 반영하겠습니다.
